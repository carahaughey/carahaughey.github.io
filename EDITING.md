# Editing your website

The site uses plain HTML and CSS, so you can update it without installing anything.

## Change text on GitHub

1. Open `github.com/carahaughey/carahaughey.github.io`.
2. Open `index.html` (home), `research.html`, `teaching.html`, or `contact.html`.
3. Click the pencil icon (**Edit this file**).
4. Find the visible sentence you want to replace. The homepage also has `EDIT HERE` comments.
5. Change only the words between tags—for example, `<p>Replace this sentence.</p>`.
6. Click **Commit changes**. GitHub republishes the site automatically.

## Replace a PDF or portrait

Upload a replacement with the exact same filename:

- Portrait: `assets/cara-haughey.jpg`
- CV: `cv/cara-haughey-cv.pdf`
- Fracking paper: `papers/fracking-healthcare-utilization.pdf`

## Change colors

Open `assets/styles.css`. The palette is at the top under `:root`; the main colors are `--burgundy` and `--navy`.

## A safe habit

Change one page at a time, commit it, and check the live website. GitHub keeps the full history, so an earlier version can always be restored.
